# Data

All numbers below are copied from `data/processed/data_stats.json` (written by `src/prepare_data.py`).

## Source
- **Dataset:** [`openbmb/UltraFeedback`](https://huggingface.co/datasets/openbmb/UltraFeedback) (Cui et al., 2023), raw JSONL files `evol_instruct`, `false_qa`, `flan`, `sharegpt`, `truthful_qa`, `ultrachat`.
- **Licence:** MIT (as declared on the Hugging Face dataset card). Prompts come from public instruction datasets (Evol-Instruct, FLAN, ShareGPT, TruthfulQA, FalseQA, UltraChat); responses were generated by the UltraFeedback authors in 2023. No private data was collected by us.
- **Fields used:** `source` (sub-dataset), `instruction` (= LLM_Input), `completions[i].model` (= LLM_name), `completions[i].response` (= LLM_Output). Annotation fields (ratings, critiques) are ignored.
- **Raw size:** 63,967 prompts (63,936 unique) x 4 completions = 255,864 (prompt, model, response) triples from 17 models. Each prompt was answered by 4 models drawn at random from the pool, so **prompts repeat across models** in the raw data.
- **Privacy caveat:** some prompts come from ShareGPT (conversations shared by real users). The MIT licence does not by itself guarantee they contain no personal or third-party content; we did not audit them.
- **Caveat:** UltraFeedback generated each completion under a randomly chosen "principle" system prompt (helpfulness / honesty / truthfulness / verbalised calibration). The system prompt is not part of our input, but it affects response style for all models equally in expectation.

## Prompt repetition and source imbalance
- After downsampling, 15,904 prompts have one response, 1,892 have two, 100 have three, 3 have four; 1,880 prompts are answered by more than one family.
- Bard has **no** responses for the FLAN sub-sets `flan_v2_niv2`, `flan_v2_p3`, `flan_v2_flan2021` and is over-represented in `evol_instruct` (1,064 vs ~650 for other families) and `ultrachat`. This source/label correlation is a known leakage channel for input-only classification (see RQ2).

## Reproduce
```
python -c "from huggingface_hub import hf_hub_download as d; [d('openbmb/UltraFeedback', f, repo_type='dataset', local_dir='data/raw') for f in ['evol_instruct.jsonl','false_qa.jsonl','flan.jsonl','sharegpt.jsonl','truthful_qa.jsonl','ultrachat.jsonl']]"
python src/prepare_data.py
```
Output: `data/processed/dataset.parquet` (columns `prompt_id, source, task, model, family, prompt, response, split`) and `data/processed/data_stats.json`.

**Redaction.** One source prompt (prompt_id 741) contains what looks like a live Discord bot token pasted by the original user; it also appears in one response. In the committed parquet those 3 occurrences were replaced with `<REDACTED_TOKEN>` after the experiments ran, so the file's md5 (`ca24e725...`) differs from the `data_md5` recorded in `results/runs/*.json` (`7b7eec9d...`). Rebuilding from the raw data reproduces the unredacted file. The change touches 3 of 40,000 text fields and does not affect the reported results.
